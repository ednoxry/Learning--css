## ✨ Sobre o projeto

O **CSS Playground** é um projeto criado para explorar o potencial do CSS,
experimentando animações, efeitos interativos, layouts responsivos
e interfaces modernas sem depender de frameworks.

O objetivo é praticar desenvolvimento front-end, aprimorar habilidades
de estilização e construir uma coleção de componentes reutilizáveis.

## 🚀 Funcionalidades

- 🌌 Interface moderna com tema escuro
- 💜 Gradientes e efeitos neon
- ✨ Botões com efeitos hover
- 🪄 Animações com CSS Keyframes
- 🔄 Indicador de carregamento animado
- 📱 Layout responsivo
- 🎯 Navegação com rolagem suave
- 🧩 Componentes feitos com CSS puro

## 🛠️ Tecnologias

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- CSS Variables
- Transitions e Transforms
- Keyframes e animações

## 💻 Como executar

Clone o repositório:

```bash
git clone https://github.com/SEU_USUARIO/css-playground.git
```

Entre na pasta:

```bash
cd css-playground
```

Inicie um servidor local com Python:

```bash
python -m http.server 8080
```

Abra no navegador:

```text
http://localhost:8080
```

Você também pode abrir o arquivo `index.html` diretamente no navegador.
